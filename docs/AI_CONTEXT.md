# AI 컨텍스트

이 문서는 Codex/AI 세션을 위한 지속 프로젝트 메모리입니다. 리젠, 컨텍스트 손실, 긴 대화로 인한 렉을 줄이기 위해 사용합니다.

## 우선순위 규칙

- 이 저장소를 열면, 특히 리젠된 대화라면 이 파일을 먼저 읽습니다.
- 시스템/개발자 지침과 사용자의 최신 명시 요청이 항상 더 우선합니다.
- 최신 채팅 요청이 이 문서와 충돌하면 최신 채팅 요청을 따릅니다.
- 오래된 채팅 기록에 의존하지 말고, 안정적으로 유지해야 하는 프로젝트 맥락은 여기에 적습니다.
- 일회성 대화, 임시 로그, 민감정보, 토큰, 비밀번호, 개인 계정 정보는 저장하지 않습니다.

## 리젠 후 복구 흐름

1. `AGENTS.md`를 읽습니다.
2. 이 파일 `docs/AI_CONTEXT.md`를 읽습니다.
3. 현재 요청에 필요한 코드, 설정, 문서만 추가로 확인합니다.
4. 이전 대화 전체를 복원하려 하지 말고, 이 문서와 사용자의 최신 요청을 기준으로 이어서 작업합니다.
5. 새로 생긴 안정적인 결정사항이 있으면 이 파일에 짧게 추가합니다.

## 사용자 선호

- 사용자는 보통 한국어로 소통합니다.
- 사용자는 긴 프롬프트를 계속 넣어서 채팅이 느려지는 상황을 피하고 싶어합니다.
- 사용자는 지속 프로젝트 맥락을 채팅이 아니라 Markdown 문서에 저장하길 원합니다.
- 사용자는 바로 실행 가능한 실용적인 답변을 선호합니다.

## 지속 결정사항

- 리젠이나 컨텍스트 손실 후에는 Codex가 `docs/AI_CONTEXT.md`를 먼저 읽습니다.
- 필요한 맥락이 이 파일에 있어야 한다면, Codex는 이전 대화 전체를 복구하려 하지 않습니다.
- 앞으로도 도움이 될 지속 컨텍스트가 생기면 이 파일에 추가합니다.
- 임시 구현 로그, 원본 터미널 출력, 불확실한 추측은 지속 결정사항으로 기록하지 않습니다.
- 2026-05-22: 인증 방향은 교수님 조언에 맞춰 Firebase가 아니라 FastAPI 자체 JWT 로그인 방식으로 진행합니다.
- 2026-06-15: My Tasks는 `assignee_id` 기준으로 정리했고, 프론트에 Inbox MVP, Reporting MVP, 빈 상태/검색 결과 없음 UX를 추가했습니다.
- 2026-06-16: Space CRUD API와 프론트 Space 선택/생성/수정/삭제 UI를 추가했고, 프로젝트/작업 목록은 활성 Space 기준으로 조회합니다.
- 2026-06-16: Space 멤버 관리 MVP를 추가했습니다. 가입된 사용자 이메일로 멤버를 추가하고 `admin/member/viewer` 역할 변경 및 제거가 가능합니다.
- 2026-06-16: Space 역할 기반 권한 검증을 백엔드에 적용했습니다. `viewer`는 조회만, `member`는 작업 쓰기, `admin`은 Space/Project/멤버 관리가 가능합니다.
- 2026-07-07: 프론트 Home 화면에 Space 역할 배지와 역할별 UI 제어를 추가했습니다. `admin`은 Space/Project 관리, `admin/member`는 작업 쓰기, `viewer`는 조회 중심으로 버튼/드래그를 제한합니다.
